# Oasis — cliente

Instancia del pack para jugadores (Prism / CurseForge / Modrinth App).

## Setup recomendado (Prism Launcher)

1. Crear instancia: Minecraft **1.21.1** + NeoForge **21.1.253**
2. RAM: **6144 MB**
3. Java: **21**
4. Copiar contenidos de `mods/` y `config/` de esta carpeta a la instancia
5. Unirse al servidor Oasis

Los mods client-only viven solo aqui, no en `../server/mods`.
