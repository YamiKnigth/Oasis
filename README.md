# Oasis

Modpack cozy-adventure (Minecraft **1.21.1** / NeoForge **21.1.253**) para hasta 5 jugadores.

Este repo versiona **configs, KubeJS, FTB Quests y el perfil CurseForge**.  
**No** incluye jars de mods.

## Instalar (jugadores)

1. CurseForge App + **Java 21**
2. Importar `curseforge/Oasis-1.0.0.zip`
3. RAM **6144 MB**

Ver `docs/INSTALL.md`.
